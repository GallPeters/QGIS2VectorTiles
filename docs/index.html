Features

Your QGIS styling, carried all the way to the browser.

Design in the tool you know. QGIS2VectorTiles takes care of tiling, styling and packaging, and keeps what you see in QGIS on the web.

Large datasets

Sources are clipped to your extent, read once, cached between runs and processed in parallel.

Complex styling

Rule-based, categorized and graduated renderers, labels and geometry generators become tile-ready rules.

Data-style coupling

Data-defined properties are evaluated per feature and stored with the data, so every value renders exactly.

Familiar GUI

A standard QGIS Processing tool. Choose the extent, zoom range and viewer, then run.

Compact output

Each layer is written only to its own zoom range, with only the fields its style uses.

Client-side rendering

The browser draws the tiles with MapLibre or OpenLayers. No map server, sharp at every zoom.

No dependencies

Runs on the Python and GDAL that ship with QGIS. No internet connection, nothing extra to install.

Open standards

Vector tiles in MBTiles, a MapLibre GL style and a QGIS layer file: formats the web-mapping world reads.

How it works

One folder, ready to use.

Every run writes the tiles, the style and a ready-to-use viewer side by side.

Output package6 parts
  • Vector tiles archive.mbtiles
  • Styled QGIS layer.qlr
  • MapLibre style sheet.json
  • Icon sprites.png & .json
  • Standalone viewerindex.html
  • Font glyphs.pbf

Open it anywhere. A standalone web viewer and a .qlr layer are included, so the same tiles open in a browser and back in QGIS.

Use cases

Fits the stack you already have.

One export, three ways to use it.

01

Client-side rendering

Drop the MapLibre style into your web map client. No server processing or on-the-fly rasterization, just fast, sharp, fully styled vector tiles rendered natively.

Mapbox MapTiler MapLibre OpenLayers

Compatible with Vector Tiles and GL Styles.

02

Web map services

Serve vector tiles through standard GIS infrastructure. Benefit from smaller payloads, faster response times, and a single source of truth for your styles.

GeoServer QGIS Server

Using the MBTiles and MBStyle extensions.

03

Project sharing

Share a single styled layer file instead of dozens of datasets, projections, and dependencies. The complex multi-source project is collapsed with visuals baked in.

1× source 1× .qlr layer

Standard QGIS layer definition format.
